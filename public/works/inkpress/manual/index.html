E-INK PDF / COMIC VIEWER

InkPress 取扱説明書

BOOX などの E-ink（電子ペーパー）端末に最適化した、PDF・コミック・自炊書籍のための静かなビューアです。残像やちらつきを抑え、紙のように落ち着いて読めます。

バージョン 1.2.8 対応 Android 8.0 以上

本書は全機能を網羅した説明書です。目次から知りたい項目へ飛んでください。

主な機能

よく使う操作をまとめました。詳しい手順は各章を参照してください。

ページめくり

画面の左右タップで前後のページへ。漫画は右→左めくりにも対応。

見開き表示

横画面で2ページを並べて表示。ズレ補正もワンタップ。

余白の自動トリミング

紙面の余白を自動で切り取り、文字や絵を大きく表示。

手書きメモ

ペンアイコンで手書きモードに入り、ページへ直接書き込み。

フォルダ作成

本を別の本へ重ねてドラッグすると、フォルダにまとめられます。

クラウド同期

Dropbox・WebDAV（自宅 NAS など）と連携し、複数の端末から続きを読めます。

対応ファイルと端末

  • 対応フォーマット：PDF / ZIP / CBZ / RAR / CBR / 画像（JPG・PNG・WEBP・BMP・GIF）
  • 対応端末：Android 8.0 以上。BOOX/Onyx などの E-ink 端末に最適化（一般の Android 端末でも動作）
  • 暗号化された PDF はパスワードを入力して開けます。

ライブラリ（本棚）の使い方

本を開く・探す

  • 本をタップすると開きます。フォルダはタップで中に入り、上部のホーム／戻るボタンや端末の戻るキーで移動します。
  • 画面上部の「最近読んだ本」カードから直前の本をすぐ再開できます（× で非表示）。
  • 引っ張って更新で本棚を再スキャンします（フォルダに変更がなければ高速にスキップ）。

並べ替え・整理

  • 上部の並べ替えアイコンで、名前（A-Z / Z-A）・日付（新しい / 古い）・カスタム（手動）を選べます。
  • ドラッグ＆ドロップ：本を長押ししてドラッグで並べ替え。本を別の本に重ねるとフォルダが作成されます（自動でカスタム順に切替）。
  • 複数選択：本を長押し →「複数選択」で、まとめて操作できます。

本ごとのメニュー（長押し）

本を長押しすると、次の操作ができます。

読書設定（レイアウト） 表紙：ページ指定／トリミング 名前変更 情報（ファイル詳細） 履歴から削除 削除

削除について

⚠ 注意

既定の「削除」はライブラリから隠すだけで、ファイル自体は残ります。隠した本は「設定 → 本棚とファイル → 隠した本を元に戻す」で元に戻せます。

ファイルごと消したい場合は、「設定 → 本棚とファイル」で「ファイルごと完全に消せるようにする」を ON にしてください（赤字の警告つき。本棚のルートフォルダは削除できません）。

表紙とファイル名の表示

  • 表紙サイズは小／中／大から選べます（設定 → 本棚とファイル。設定ホーム上部の「よく変えるもの」からも変えられます）。
  • サムネイル下のファイル名・拡張子の表示は個別に ON/OFF できます。

  • ピンチで拡大縮小（最大 4 倍）、ダブルタップで全体表示に戻す（拡大の解除）。

  • クイック調整：コントラスト／彩度／モノクロをその場でプレビューしながら調整できます。

移動・ナビゲーション

  • 中央タップで上下のメニューバーを表示。
  • 目次（TOC）：PDF の目次タブとサムネイル一覧タブからジャンプ。
  • ページ番号ジャンプ：番号を入力して移動。

進捗の保存

読書位置はアプリを切り替えたり画面が消えたときに自動保存され、次回は続きから開けます（「設定 → 読む → 最後に読んだ本をすぐ開く」で起動時に自動で開くこともできます）。

6

E-ink 最適化

E-ink（電子ペーパー）端末で快適に読むための機能です。

  • 全体リフレッシュ（残像クリア）：BOOX/Onyx 端末では GC16 ハードフラッシュで残像（ゴースト）を一掃します（非 Onyx 端末ではソフトフラッシュ）。「設定 → 画面と見え方 → E-inkリフレッシュ」で ON／OFF を切り替え、書き直す頻度を自動／毎ページ／3ページごと／5ページごとから選べます。
  • コントラスト調整・ディザリング：薄い文字をくっきり、画像を E-ink 向け白黒に。
  • ページの描き方：高画質／速さ優先を選べます。
  • スリープ（画面オフ）：リーダー左上の月アイコンで画面を消灯（端末をロック）。電源ボタンが押しにくい E-ink 端末向けです。
🔒 プライバシーについて

スリープ機能は端末のアクセシビリティサービスを使い、有効化した場合のみ動作します。画面の内容は一切読み取らず、データの収集・送信もありません。

8

フォルダロック（PIN・指紋）

人に見られたくない本を、フォルダごと隠せます（1.2.7 で追加）。

できること

  • 本棚のフォルダに PIN（4〜6 桁）で鍵をかけます。PIN はアプリ全体で 1 つです。
  • 指紋・顔でも解除できます（PIN がマスターなので、PIN は必ず設定します）。
  • ロック中のフォルダにある本は、ウィジェット・全注釈ビュー（マイノート）・読書履歴に一切出ません。
  • ロック中の本を読んでいるあいだは、アプリ切替画面のサムネイルが白紙になります。

鍵のかけかた

ライブラリでフォルダを長押し →「フォルダをロック」。初回はここで PIN を決めます。鍵を外すときは同じく長押し →「ロックを外す」。

ロック中の見た目

フォルダごとに選べます。

  • 鍵マークを表示 … 鍵がかかっていることが分かる見た目。
  • 普通のフォルダに見せかける … 表紙のないフォルダとして並び、鍵の存在自体に気づかれません。

鍵がかかり直すタイミング

「設定 → フォルダロック」で決めます。

  • アプリを離れてから … すぐ／1 分後／5 分後／15 分後
  • 画面が消えたらすぐ再ロック … ON にすると、時間を待たずにロックし直します。

解除中（開いた鍵の状態）は、ほかのロックフォルダも PIN なしで開けます。

PIN を忘れたら

「設定 → フォルダロック → PIN を忘れた（リセット）」で、すべてのロックを外せます。本もメモも消えません。隠れていた本が見える状態に戻るだけです。

🔒 金庫ではなくカーテンです

ファイルそのものは暗号化していません。パソコンにつないだり、ほかのファイルアプリで開けば中身は見えます。金庫ではなくカーテンとお考えください。のぞき見を防ぐための機能です。

連携のしかた

「設定 → クラウドと同期 → Dropbox を接続」。自宅の NAS や Nextcloud は「自宅サーバー / NAS を接続」から登録します（WebDAV）。Nextcloud や Synology などに対応しており、サーバー URL・ユーザー名・パスワードを入力します（パスワードは各サーバーで発行する「アプリパスワード」の利用を推奨。自己署名証明書の NAS 向けに許可オプションもあります）。接続すると、下の読書位置・注釈のスイッチが使えるようになります（接続前はグレーアウト）。

同期される内容

対象 仕組み
読書位置最も先まで読んだ位置を採用（後退しても下げない）。別端末で開くと「リモートが先まで読んでいます」と確認ダイアログが出て、続きへジャンプできます（Kindle 風）。
レイアウト設定新しい方を静かに反映（見開き・読み方向・ズームロック等）。
注釈しおり・メモ・手書きをそれぞれ突き合わせて統合。削除も他端末へ伝わります。
読書履歴統合（別端末で読んだ本が「最近読んだ」に出る）。
  • 本の同定はファイルの内容で行うため、端末ごとに保存場所が違っても同じ本として扱われます。
  • クラウドから取り込み：Dropbox や WebDAV 上のファイルを選び、保存先の本棚フォルダを指定してダウンロードできます。クラウド上のフォルダをそのまま本棚として登録することもできます。
  • ストリーミング表示：コミック（CBZ）は全体をダウンロードせず、開いたページから読み始められます（下の「クラウドの本の開き方」で選べます）。それ以外（PDF・RAR など）は端末に取り込んでから開きます。ダウンロードは途中で中断しても再開できます。
  • アカウントは一覧で確認でき、切断もできます（認証情報は暗号化して保存）。

クラウドの本の開き方

「設定 → クラウドと同期 → クラウドの本の開き方」で選べます（コミック＝CBZ が対象）。

選択肢 動き
自動回線とファイルの大きさを見て、アプリが選びます（既定）。
ストリーミング全体を落とさず、必要なページだけ読み込みます。すぐ読み始められます。
ダウンロード先に丸ごと保存してから開きます。オフラインでも読めます。

1.2.7 から、自宅サーバー / NAS のコミックもストリーミングで開けます。読書中に通信が切れたときは、ダウンロードへの切り替えをご案内します。

読書位置・注釈の同期は Dropbox のみです。自宅サーバー / NAS は本棚として使えますが、同期の対象にはなりません。

モバイル回線のときは通信量を抑えるため、表紙の自動生成を行いません。

困ったときに（FAQ）

Q
本が表示されない
A

「設定 → 本棚とファイル」で本棚フォルダが登録されているか確認し、本棚を引っ張って更新してください。対応していない形式は表示されません（→ 01章）。

Q
削除したのにファイルが残る／消したくない
A

既定の削除はライブラリから隠すだけです。完全に消すには「ファイルごと完全に消せるようにする」を ON に（→ 03章）。隠した本は「設定 → 本棚とファイル → 隠した本を元に戻す」から戻せます。

Q
別の端末で続きから読めない
A

両方の端末で同じ Dropbox に接続し、「読書位置」の同期を ON にしてください（→ 09章）。

Q
残像（ゴースト）が残る
A

「E-ink リフレッシュ」を自動または短い間隔に設定してください（→ 06章）。

Q
画面が消せない（E-ink 端末）
A

リーダー左上の月アイコンでスリープ。初回はアクセシビリティの有効化が必要です（→ 06章）。

Q
フォルダの PIN を忘れた
A

「設定 → フォルダロック → PIN を忘れた（リセット）」ですべてのロックを外せます。本もメモも消えません（→ 08章）。

Q
文字が薄い／読みにくい
A

本の設定でコントラストを上げる、モノクロ（ディザリング）を ON、自動トリミングで拡大してください（→ 04章・05章）。

開発を応援いただける方は、アプリ内「設定 → アプリについて → Ko-fi で開発を応援する」からどうぞ。いつもありがとうございます。

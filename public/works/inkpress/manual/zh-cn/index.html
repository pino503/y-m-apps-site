InkPress 使用说明书

为 BOOX 等墨水屏（电子纸）设备优化的 PDF、漫画与扫描书 安静阅读器 。它能抑制残影和闪烁，让你像读纸书一样平静地阅读。

版本 1.2.9 需要 Android 8.0 及以上

本说明书涵盖所有功能。可从 目录 直接跳到需要的主题。

主要功能

这里汇总了最常用的操作。详细步骤请参阅各章。

翻页

点击屏幕左右两侧即可翻页。也支持漫画用的从右到左翻页。

双页显示

横屏时并排显示两页。页面对齐也能一键修正。

自动裁剪边距

自动裁掉页面边距，让文字和插图显示得更大。

手写笔记

点击画笔图标进入手写模式，即可直接在页面上书写。

新建文件夹

把一本书拖到另一本书上，即可归为一个文件夹。

云端同步

连接 Dropbox 或 WebDAV（例如家用 NAS），就能在多台设备上接着阅读。

1

支持的文件与设备

  • 支持格式：PDF / ZIP / CBZ / RAR / CBR / 图片（JPG、PNG、WEBP、BMP、GIF）
  • 支持设备：Android 8.0 及以上。针对 BOOX/Onyx 等墨水屏设备优化（普通 Android 设备也能使用）。
  • 加密的 PDF 只需输入 密码即可打开。

使用书库

打开与查找书籍

  • 点击书即可打开。点击文件夹会进入其中，可用顶部的 主页 / 返回 按钮或设备的返回键移动。
  • 通过屏幕顶部的 “最近阅读”卡片 可立即继续最近的书（点击 × 可隐藏）。
  • 下拉刷新 即可重新读取书库（文件夹没有变化时会很快完成）。

排序与整理

  • 用顶部的 排序图标 选择名称（A-Z / Z-A）、日期（从新到旧 / 从旧到新）或 自定义（手动）排序。
  • 拖放：长按书并拖动即可调整顺序。把书放到另一本书上就会 新建文件夹 （会自动切换为自定义排序）。
  • 多选：长按书 → “多选”即可一次处理多本。

书的菜单（长按）

长按书可使用以下操作。

阅读设置（版面） 封面：选择页面 / 裁剪 重命名 信息（文件详情） 从记录中移除 删除

关于删除

⚠ 注意

默认的“删除”只会 从书库中隐藏这本书，文件本身仍会保留。隐藏的书可在“设置 → 书架与文件 → 恢复隐藏的书”中恢复。

若要删除文件本身，请在“设置 → 书架与文件”中开启 “允许删除文件本身” （会以红字显示警告；书库的根文件夹无法删除）。

封面与文件名显示

  • 封面大小可选 小 / 中 / 大 （设置 → 书架与文件；放进设置首页顶部的“常用”后，也能在那里修改）。
  • 缩略图下方的 文件名和扩展名 显示可分别开关。

翻页

点击
  • 横向（翻页）模式 … 屏幕的 左侧 30% 和右侧 30% 用于翻页， 中央 40% = 菜单。在 漫画模式（从右到左，默认）下，左 = 下一页、右 = 上一页；从左到右模式则是左 = 上一页、右 = 下一页。
  • 纵向滚动模式 … 上方 25% = 上一页、 下方 25% = 下一页、 中央 50% = 菜单。
  • 滑动：左右滑动即可翻页（纵向模式为上下）。可在设置 → 阅读 → 滑动翻页中关闭；放大时滑动会改为移动画面。
  • 翻页动画 （设置 → 阅读）会让页面跟随手指移动。墨水屏设备上请保持关闭（墨水屏上默认关闭）。
  • 音量键：音量减 = 下一页，音量加 = 上一页。可在设置中反转。
💡 提示

只用电源键和音量键也能阅读，在墨水屏设备上非常方便。

缩放与显示

  • 双指缩放 可放大缩小（最多 4 倍）， 双击 即可回到整页显示（重置缩放）。
  • 自动裁剪：检测边距并自动放大，让文字显示得更大（通过阅读界面的菜单按钮）。
  • 锁定缩放/位置：固定缩放倍率和位置，让每一页都以相同范围阅读（适合裁剪扫描书的边距）。
  • 快速调整：边预览效果，边当场调整对比度、饱和度和黑白。

移动与导航

  • 点击中央 会显示上下菜单栏。
  • 目录（TOC）：可从 PDF 的目录标签和 缩略图列表标签跳转。
  • 跳转到页码：输入数字即可前往该页。

保存进度

切换应用或屏幕关闭时，阅读位置会自动保存，下次可从原处继续（也可通过“设置 → 阅读 → 启动时打开上次的书”在启动时自动打开）。

6

墨水屏优化

让墨水屏（电子纸）设备阅读更舒适的功能。

  • 全屏刷新（清除残影）：在 BOOX/Onyx 设备上以 GC16 硬刷新完全清除残影（其他设备为软刷新）。在“设置 → 显示与外观 → 墨水屏刷新”中可开启或关闭，并选择重绘频率： 自动 / 每页 / 每 3 页 / 每 5 页。
  • 对比度调整与抖动：让浅色文字更清晰，并把图片转换为适合墨水屏的黑白。
  • 页面绘制方式：选择高画质或速度。
  • 休眠（关闭屏幕）：点击阅读界面左上角的 月亮图标 即可关闭屏幕（锁定设备）。对电源键不好按的墨水屏设备很方便。如果不需要这个图标，可在设置 → 阅读 → “显示休眠（关闭屏幕）按钮”中隐藏。
🔒 关于隐私

休眠功能使用设备的 无障碍服务 ，只有在 你开启它时才会工作。它不会读取屏幕内容，也不会收集或发送任何数据。

文件夹锁（PIN 与指纹）

不想让别人看到的书，可以 以整个文件夹为单位隐藏 （1.2.7 新增）。

功能说明

  • 用 4～6 位数字 PIN锁定书库中的文件夹。整个应用共用一个 PIN。
  • 也可以用 指纹或人脸 解锁（PIN 是主钥匙，所以一定要先设置）。
  • 锁定文件夹中的书 绝不会出现在小组件、我的笔记（全部批注）或阅读记录中。
  • 阅读锁定文件夹中的书时，最近任务界面中的缩略图会保持空白。

锁定文件夹

在书库中长按文件夹并选择 “锁定文件夹” 。首次会在这里设置 PIN。要解除锁定，再次长按并选择“解除锁定”。

锁定文件夹的外观

可为每个文件夹分别选择。

  • 显示锁图标 — 一眼就能看出文件夹已锁定。
  • 伪装成普通文件夹 — 以没有封面的文件夹放在书架上，没人会发现它被锁定。

重新锁定的时机

在“设置 → 文件夹锁”中设置。

  • 离开应用后 — 立即 / 1 分钟后 / 5 分钟后 / 15 分钟后
  • 屏幕关闭时立即重新锁定 — 开启后会不等待直接重新锁定。

解锁期间（锁打开），其他锁定的文件夹也无需 PIN 即可打开。

忘记 PIN 时

“设置 → 文件夹锁 → 忘记 PIN（重置）”会解除所有文件夹的锁定。 不会删除任何书或笔记。 隐藏的书只是重新显示而已。

🔒 是窗帘，不是保险箱

文件本身不会加密。把设备连接到电脑或用其他文件应用打开，仍然能看到内容。请把它理解为 窗帘而不是保险箱 — 用来防止别人从旁偷看。

连接方式

前往“设置 → 云端与同步 → 连接 Dropbox”。家里的 NAS 或 Nextcloud 请用“连接家用服务器 / NAS”（WebDAV），输入服务器 URL、用户名和密码（建议使用服务器生成的“应用专用密码”；也有允许家用 NAS 自签名证书的选项）。连接后，下方的 阅读位置和批注 开关即可使用（连接前为灰色不可用）。

同步的内容

项目 工作方式
阅读位置读得最远的位置优先（即使往回翻也不会倒退）。在其他设备打开书时，会弹出“在其他设备读得更远”的确认对话框，可直接跳转过去（Kindle 方式）。
版面设置较新的设置会静默应用（双页、阅读方向、缩放锁定等）。
批注书签、笔记和手写会分别比对并合并。删除也会同步到其他设备。
阅读记录合并（在其他设备读过的书也会出现在“最近阅读”中）。
  • 书是按 文件内容识别的，因此即使各设备的存储位置不同，也会视为同一本书。
  • 从云端导入：选择 Dropbox 或 WebDAV 上的文件，指定存放的书库文件夹后下载。也可以把云端文件夹本身添加为书架。
  • 流式读取：漫画（CBZ）无需下载整个文件，可从打开的页面直接开始（见下方“云端书籍的打开方式”）。PDF、RAR 等其他格式会先下载到设备。中断的下载会从中断处继续。
  • 账户可在列表中查看，也能断开连接（登录信息会加密保存）。

在“设置 → 云端与同步 → 云端打开方式”中选择（适用于漫画，即 CBZ 文件）。

选项 作用
自动根据连接状态和文件大小由应用决定（默认）。
流式读取只加载需要的页面而不是整个文件，可以马上开始阅读。

常见问题（FAQ）

Q
书没有显示出来
A

请确认“设置 → 书架与文件”中已添加书库文件夹，再下拉刷新书库。不支持的格式不会显示（→ 第 01 章）。

Q
删除后文件还在 / 不想删除文件
A

默认的删除只会从书库中隐藏。若要彻底删除，请开启“允许删除文件本身”（→ 第 03 章）。隐藏的书可在“设置 → 书架与文件 → 恢复隐藏的书”中恢复。

Q
无法在其他设备上继续阅读
A

请将两台设备连接到同一个 Dropbox 账户，并开启“同步阅读位置”（→ 第 09 章）。

Q
屏幕上残留残影
A

请将“墨水屏刷新”设为自动或较短的间隔（→ 第 06 章）。

Q
无法关闭屏幕（墨水屏设备）
A

请用阅读界面左上角的月亮图标休眠。首次需要开启无障碍功能。若没有图标，请确认设置 → 阅读 → “显示休眠（关闭屏幕）按钮”没有关闭（→ 第 06 章）。

Q
忘记了文件夹的 PIN
A

“设置 → 文件夹锁 → 忘记 PIN（重置）”会解除所有文件夹的锁定。不会删除书或笔记（→ 第 08 章）。

Q
书一直加载不完
A

如果书在一段时间后仍在加载，InkPress 会询问要继续等待还是返回书库。请选择“返回书库”后重新打开；云端书籍也请检查网络连接（→ 第 09 章）。

Q
文字太淡 / 不好阅读
A

在书的设置中提高对比度、开启黑白（抖动），并用自动裁剪放大（→ 第 04、05 章）。

如果愿意支持开发，请通过应用中的 “设置 → 帮助与支持 → 在 Ko-fi 支持开发” 。一直以来非常感谢。

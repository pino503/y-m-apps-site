InkPress 使用說明書

為 BOOX 等 E-ink（電子紙）裝置最佳化的 PDF、漫畫與掃描書 安靜閱讀器 。它能抑制殘影與閃爍，讓你像讀紙本一樣平靜地閱讀。

版本 1.3.0 需要 Android 8.0 以上

本說明書涵蓋所有功能。請從 目錄 直接跳到需要的主題。

主要功能

這裡整理了最常用的操作。詳細步驟請見各章。

翻頁

點畫面左右兩側即可翻頁。也支援漫畫用的由右至左翻頁。

雙頁顯示

橫向時並排顯示兩頁。頁面對齊也能一點就修正。

自動裁切邊界

自動裁掉頁面邊界，讓文字與插圖顯示得更大。

手寫筆記

點筆圖示進入手寫模式，即可直接在頁面上書寫。

建立資料夾

把一本書拖到另一本書上，就能整理成一個資料夾。

雲端同步

連線 Dropbox 或 WebDAV（例如家用 NAS），就能在多台裝置上接續閱讀。

1

支援的檔案與裝置

  • 支援格式：PDF / ZIP / CBZ / RAR / CBR / 圖片（JPG、PNG、WEBP、BMP、GIF）
  • 支援裝置：Android 8.0 以上。針對 BOOX/Onyx 等 E-ink 裝置最佳化（一般 Android 裝置也能使用）。
  • 加密的 PDF 只要輸入 密碼即可開啟。

3

使用書庫

開啟與尋找書籍

  • 點書即可開啟。點資料夾會進入其中，並可用上方的 首頁 / 返回 按鈕或裝置的返回鍵移動。
  • 從畫面上方的 「最近讀過」卡片 可立即接續最近的書（點 × 可隱藏）。
  • 下拉重新整理 即可重新讀取書庫（資料夾沒有變更時會很快完成）。

排序與整理

  • 用上方的 排序圖示 選擇名稱（A-Z / Z-A）、日期（由新到舊 / 由舊到新）或 自訂（手動）排序。
  • 拖放：長按書並拖曳即可調整順序。把書放到另一本書上就會 建立資料夾 （會自動切換為自訂排序）。
  • 多選：長按書 → 「多選」即可一次處理多本。

書的選單（長按）

長按書可使用以下操作。

閱讀設定（版面） 封面：選擇頁面 / 裁切 重新命名 資訊（檔案詳細資料） 從紀錄移除 刪除

關於刪除

⚠ 注意

預設的「刪除」只會 從書庫隱藏這本書，檔案本身仍會保留。隱藏的書可從「設定 → 書架與檔案 → 還原隱藏的書」還原。

若要刪除檔案本身，請在「設定 → 書架與檔案」開啟 「允許刪除檔案本身」 （會以紅字顯示警告；書庫的根資料夾無法刪除）。

封面與檔名顯示

  • 封面大小可選 小 / 中 / 大 （設定 → 書架與檔案；放進設定首頁最上方的「常用」後，也能在那裡變更）。
  • 縮圖下方的 檔名與副檔名 顯示可分別開關。

翻頁

點按
  • 橫向（翻頁）模式 … 畫面的 左側 30% 與右側 30% 用來翻頁， 中央 40% = 選單。在 漫畫模式（由右至左，預設）下，左 = 下一頁、右 = 上一頁；由左至右模式則是左 = 上一頁、右 = 下一頁。
  • 直向捲動模式 … 上方 25% = 上一頁、 下方 25% = 下一頁、 中央 50% = 選單。
  • 滑動：左右滑動即可翻頁（直向模式為上下）。可在設定 → 閱讀 → 滑動翻頁關閉；放大時滑動會改為移動畫面。
  • 翻頁動畫 （設定 → 閱讀）會讓頁面跟著手指移動。E-ink 裝置上請保持關閉（E-ink 上預設為關閉）。
  • 音量鍵：音量下 = 下一頁，音量上 = 上一頁。可在設定中反轉。
💡 提示

只用電源鍵和音量鍵也能閱讀，在 E-ink 裝置上非常方便。

縮放與顯示

  • 用兩指縮放 可放大縮小（最多 4 倍）， 點兩下 即可回到整頁顯示（重設縮放）。
  • 自動裁切：偵測邊界並自動放大，讓文字顯示得更大（從閱讀畫面的選單按鈕）。
  • 鎖定縮放/位置：固定縮放倍率與位置，讓每一頁都以相同範圍閱讀（適合裁切掃描書的邊界）。
  • 快速調整：一邊預覽效果，一邊當場調整對比、飽和度與黑白。

移動與導覽

  • 點中央 會顯示上下方的選單列。
  • 目錄（TOC）：可從 PDF 的目錄分頁與 縮圖清單分頁跳轉。
  • 跳至頁碼：輸入數字即可前往該頁。

儲存進度

切換應用程式或螢幕關閉時，閱讀位置會自動儲存，下次可從原處接續（也可透過「設定 → 閱讀 → 啟動時開啟上次的書」在啟動時自動開啟）。

6

E-ink 最佳化

讓 E-ink（電子紙）裝置閱讀更舒適的功能。

  • 全螢幕重新整理（清除殘影）：在 BOOX/Onyx 裝置上以 GC16 硬閃完全清除殘影（其他裝置為軟閃）。在「設定 → 顯示與外觀 → E-ink 重新整理」可開啟或關閉，並選擇重繪頻率： 自動 / 每頁 / 每 3 頁 / 每 5 頁。
  • 對比調整與抖色：讓淡色文字更清楚，並把圖片轉換為適合 E-ink 的黑白。
  • 頁面繪製方式：選擇高畫質或速度。
  • 休眠（關閉螢幕）：點閱讀畫面左上角的 月亮圖示 即可關閉螢幕（鎖定裝置）。對電源鍵不好按的 E-ink 裝置很方便。若不需要這個圖示，可在設定 → 閱讀 → 「顯示休眠（關閉螢幕）按鈕」隱藏。
🔒 關於隱私

休眠功能使用裝置的 無障礙服務 ，只有在 你開啟它時才會運作。它不會讀取螢幕內容，也不會收集或傳送任何資料。

資料夾鎖定（PIN 與指紋）

不想讓別人看到的書，可以 以整個資料夾為單位隱藏 （1.2.7 新增）。

功能說明

  • 用 4～6 位數的 PIN鎖定書庫中的資料夾。整個應用程式共用一組 PIN。
  • 也可以用 指紋或臉部 解鎖（PIN 是主要鑰匙，所以一定要先設定）。
  • 鎖定資料夾中的書 絕不會出現在小工具、我的筆記（所有註記）或閱讀紀錄中。
  • 閱讀鎖定資料夾中的書時，最近使用的應用程式畫面中的縮圖會保持空白。

鎖定資料夾

在書庫中長按資料夾並選擇 「鎖定資料夾」 。第一次會在這裡設定 PIN。要解除鎖定，再次長按並選擇「解除鎖定」。

鎖定資料夾的外觀

可為每個資料夾分別選擇。

  • 顯示鎖頭圖示 — 一眼就能看出資料夾已鎖定。
  • 偽裝成一般資料夾 — 以沒有封面的資料夾放在書架上，沒人會發現它被鎖定。

重新鎖定的時機

在「設定 → 資料夾鎖定」設定。

  • 離開應用程式後 — 立即 / 1 分鐘後 / 5 分鐘後 / 15 分鐘後
  • 螢幕關閉時立即重新鎖定 — 開啟後會不等待直接重新鎖定。

解鎖期間（鎖頭打開），其他鎖定的資料夾也不需 PIN 即可開啟。

忘記 PIN 時

「設定 → 資料夾鎖定 → 忘記 PIN（重設）」會解除所有資料夾的鎖定。 不會刪除任何書或筆記。 隱藏的書只是重新顯示而已。

🔒 是窗簾，不是保險箱

檔案本身不會加密。把裝置接上電腦或用其他檔案應用程式開啟，仍然看得到內容。請把它想成 窗簾而不是保險箱 — 用來防止別人從旁偷看。

連線方式

前往「設定 → 雲端與同步 → 連線 Dropbox」。家中的 NAS 或 Nextcloud 請用「連線家用伺服器 / NAS」（WebDAV），輸入伺服器 URL、使用者名稱與密碼（建議使用伺服器核發的「應用程式密碼」；也有允許家用 NAS 自簽憑證的選項）。連線後，下方的 閱讀位置與註記 開關就能使用（連線前為灰色停用）。

設定

從書庫右上角的齒輪圖示開啟。 設定首頁 列出 8 個項目，每一列都會顯示 目前的值 （書架位置、螢幕重新整理頻率等），不用進去就能確認。

最上方的 「常用」 可放 最多 3 個 你選的設定。點一下就能在原地選擇數值，不必進入後面的畫面。一開始是 封面大小、重新整理間隔與應用程式主題。 右端的「編輯」 可從候選項目（封面大小、重新整理間隔、應用程式主題、閱讀背景、頁面繪製方式、書架顯示方式、E-ink 重新整理、滑動翻頁、動畫、開啟上次的書、檔名、休眠按鈕）中替換。勾選第 4 個時會提示「最多 3 個常用項目」。長按常用項目會開啟它所在的畫面。

資料備份點一下可選「匯出到檔案」與「從檔案匯入」兩種。對象為筆記、書籤與封面設定，不包含書本身

需要較長說明的項目，標題旁會有 「？」 （「這是什麼？」）。只有點按時才會顯示說明，平常清單也能保持清爽。

12

疑難排解（FAQ）

Q
書沒有顯示出來
A

請確認「設定 → 書架與檔案」中已登錄書庫資料夾，再下拉重新整理書庫。不支援的格式不會顯示（→ 第 01 章）。

Q
刪除後檔案還在 / 不想刪除檔案
A

預設的刪除只會從書庫隱藏。若要完全刪除，請開啟「允許刪除檔案本身」（→ 第 03 章）。隱藏的書可從「設定 → 書架與檔案 → 還原隱藏的書」還原。

Q
無法在其他裝置接續閱讀
A

請將兩台裝置連線到同一個 Dropbox 帳戶，並開啟「同步閱讀位置」（→ 第 09 章）。

Q
畫面留有殘影
A

請將「E-ink 重新整理」設為自動或較短的間隔（→ 第 06 章）。

Q
無法關閉螢幕（E-ink 裝置）
A

請用閱讀畫面左上角的月亮圖示休眠。第一次需要開啟無障礙功能。若沒有圖示，請確認設定 → 閱讀 → 「顯示休眠（關閉螢幕）按鈕」沒有關閉（→ 第 06 章）。

Q
忘記資料夾的 PIN
A

「設定 → 資料夾鎖定 → 忘記 PIN（重設）」會解除所有資料夾的鎖定。不會刪除書或筆記（→ 第 08 章）。

Q
書一直載入不完
A

若書在一段時間後仍在載入，InkPress 會詢問要繼續等待還是返回書庫。請選「返回書庫」再重新開啟；雲端書籍也請確認連線狀態（→ 第 09 章）。

Q
文字太淡 / 不好閱讀
A

在書的設定中提高對比、開啟黑白（抖色），並用自動裁切放大（→ 第 04、05 章）。

如果願意支持開發，請從應用程式的 「設定 → 說明與支援 → 在 Ko-fi 支持開發」 。一直以來非常感謝。
